# game-info-portal
## 项目介绍
纯原生HTML+CSS+JavaScript开发游戏门户综合静态页面实训项目，包含导航下拉菜单、轮播广告、游戏列表、登录面板、悬浮移动广告等完整页面模块。
## 技术栈
HTML5 / CSS3 / 原生JavaScript
## 实现功能
1. 顶部导航栏，下拉游戏分类悬浮菜单
2. 页面三栏主体布局，左侧游戏列表点击高亮激活
3. 中间轮播广告，点击圆点切换图片、窗口自适应
4. 右侧登录表单区域，完整输入框与登录按钮
5. 下方多板块游戏卡片、角色展示、新闻公告、游戏视频
6. 页面悬浮自动反弹移动广告，支持点击关闭
## 项目运行
直接双击导航菜单制作.html文件即可打开运行，图片资源存放images文件夹
## 版本管理
本项目为课程实训最终成品，仅单次提交云端归档备份，无后续迭代更新
